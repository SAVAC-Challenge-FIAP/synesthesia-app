# Previews

Capturas de tela reais do app, tiradas em release/dev build no device de teste. Convenção:

- **Uma pasta por versão** (`1.3.0/`, `1.4.0/`, ...), nome igual ao `version` de `app.json`.
- Ao lançar uma versão nova, adicione a pasta da versão nova — **não acumule** pastas por fase ou
  task como antes; a pasta da versão anterior pode ser removida quando a nova a substituir no
  README.
- `README.md` da raiz do projeto referencia só a pasta da versão atual.

`docs/previews/1.3.0/` está vazia — as capturas dessa versão ainda não foram adicionadas. Ao tirar
novas, colocar aqui.
